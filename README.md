# 📚 Book Explorer

A responsive web app for browsing and searching books, and saving your favorites.
Built as the Frontend Phase 1 Capstone at Igire Rwanda Organization (SheCanCode).

## Features
- Browse books fetched from the Open Library API
- Search books by title
- Loading spinner and "No results found" message
- Add and remove favorites, saved in localStorage
- Responsive pages: Home, Favorites, About (mobile, tablet, desktop)

## Technologies
- HTML, Tailwind CSS (CDN)
- JavaScript (ES6 modules, fetch, async/await)
- localStorage
- Git and GitHub (branches, pull requests, issues, Projects)

## How to run
1. Clone the repo: `git clone https://github.com/Anaise2005/book-explorer.git`
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
